# Employee Attrition Prediction System Using Machine Learning

## About the Project
This project uses machine learning to analyze employee data and predict whether an employee may leave or stay in an organization. It uses the Random Forest Classifier to identify patterns related to employee attrition.

## Objectives
- Analyze employee data.
- Visualize employee attrition patterns.
- Build a machine learning model.
- Evaluate model performance.
- Predict attrition for new employee details.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Algorithm Used
**Random Forest Classifier**

## Project Features
- Data cleaning and preprocessing
- Employee attrition analysis
- Department-wise attrition visualization
- Overtime and job satisfaction analysis
- Feature importance visualization
- Model evaluation using accuracy, precision, recall, and F1-score
- Prediction for new employee details

## How to Run
1. Download or clone this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries:
   `pip install pandas numpy matplotlib seaborn scikit-learn jupyter`
4. Open the project notebook in Jupyter Notebook.
5. Update the dataset file path.
6. Run all cells in order.

## Project Outcome
The system analyzes employee information and predicts whether an employee may leave or stay. It also uses visualizations to help understand attrition patterns.

## Disclaimer
This project is developed for educational purposes. Predictions are estimates and may not always be correct.
